# Provenance

How the archive was built from its sources, what changed on the way, and what was left out. The machine-readable
record is [`provenance.json`](provenance.json). For every archived file it holds the archive path, the source path,
the origin (`commit` / `disk`), the sha256 of the source and of the archived bytes, and the scrub substitutions.

Inside an A/B round, `results_*` go to `results/`, `report_*` / `summary_*` / `verify_*` to `reports/`, `*.log` to
`logs/`, and `*.bak.*` / `*.before_*` to `backups/`. File names are unchanged.

Generated by the import, from the archived data:
- `scenarios.json` and `config.json` per round;
- `excluded/excluded_<reason>.jsonl`: rows present in a backup but not in the final results file, plus
  contaminated / not-ok rows that are still in a results file;
- `provenance.json` and `scrub_report.json`.

## Scrub substitutions

Every file went through `scrub.py` during import. `scrub_report.json` has the counts per rule and folder, and
`provenance.json` has them per file. Totals for this import:

| rule | substitutions | effect |
|---|---|---|
| `home_path` | 7,732 | `/home/<user>` → `~` in result rows (`final_text`, verdict details, stderr tails), logs, code constants and outputs |
| `home_slug` | 23 | `/-home-<user>-…` path slugs (Claude Code project / scratchpad dirs) → `/-home-~-…` |
| `email` | 4 | non-allowlisted addresses → `[REDACTED:email]`: a demo account an agent guessed, a demo-shop placeholder, a truncated example address |
| keys, tokens, OAuth fields, private keys, env secret values | 0 | none were present in the committed tree |

276 of 1,245 files changed. All of them are text files whose numbers do not depend on the substituted strings.
`check_claims.py --reports` proves this for the result files: the archived analyzer regenerates the archived
reports from the scrubbed rows. The transcripts had more substitutions (e-mails from the demo sites, demo-shop API
`access_token` values, home paths), recorded per transcript in `transcripts/<round>.manifest.json`. The sha256 of
the `scrub.py` that produced the archive is recorded in `provenance.json` and in each manifest.

Code note: the scrub also rewrote absolute path constants in the archived code. For example,
`REPO = Path("~/workspace/rf-mcp-robotcode")` in the harness: `pathlib` does not expand `~`, so edit these before
rerunning (REPRODUCE.md).

## Round numbering

The folder numbers follow the research's own round numbers, so `07-v31-v32` contains `findings_v31.md` ("Round
7"). The two early A/B rounds ("A/B round 1", "A/B round 2") ran between rounds 3 and 4 and are `03a` / `03b`.
`08` is reserved for the v1 release gate (task 8.1).
